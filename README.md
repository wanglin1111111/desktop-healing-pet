# 云朵猫咪 · 桌面治愈宠物

一个单文件的桌面治愈系电子宠物：打开网页就能养一只云朵猫，带动态场景、互动道具、情绪反馈与语音。

## 特点

- **单文件，零构建**：全部代码在 `desktop-pet.html` 中，双击用浏览器打开即可运行。
- **动态场景系统**：内置多种场景背景，可随时切换。
- **情绪光环系统**：宠物状态会通过光效与粒子反馈。
- **双引擎语音**：
  - Edge TTS（微软神经网络语音，免费）通过 WebSocket 合成，音质更自然；
  - 浏览器内置 `speechSynthesis` 作为降级方案。
- **互动道具**：可对宠物进行喂食、抚摸等交互。

## 使用方式

```bash
# 直接用浏览器打开
start desktop-pet.html      # Windows
open desktop-pet.html       # macOS
```

页面内的「Edge TTS」与「浏览器语音」按钮可切换语音引擎；切换场景后会有系统提示。
